Данный пет-проект - умный помощник по отзывам с Кинопоиска. Он умеет отвечать на вопросы о фильмах, опираясь исключительно на реальные мнения зрителей, и никогда ничего не выдумывает. Если в базе нет ответа на ваш вопрос, бот честно в этом признается.

Когда вы задаете вопрос, система превращает ваш запрос в эмбеддинг и сравнивает с векторной БД отзывов, находит те, что ближе всего по смыслу. Найденные отзывы передаются локальному Qwen 2.5, который формирует связный ответ на русском языке и обязательно источники с индикацией тональности.

Для простой классификации тональности TF-IDF оказался точнее эмбеддингов (0.71 против 0.66 accuracy), потому что в коротких отзывах есть четкие слова-маркеры, которые модель легко улавливает.

Модель хуже всего предсказывает класс NEU (нейтральные отзывы), она часто путает его с POS (позитивные отзывы) из-за того, что семантика нейтральных отзывов содержит большое количество слов, присущих классу POS.
